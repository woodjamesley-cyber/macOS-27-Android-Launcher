# macOS 27 Golden Gate — Visual Reference Gallery

A curated set of real macOS 27 Golden Gate screenshots gathered before any code was written. Each entry lists the image, its original source, the feature category and exactly what this launcher should recreate from it.

> **Copyright and licensing.** Every image here is a screenshot captured by Apple or by a publication reviewing macOS. Copyright remains with those owners. Images are **not** bundled with the app, are **not** committed to this repository, and are **not** redistributed. The committed gallery hotlinks the originals for study; a local cache can be regenerated with `python3 tools/collect_references.py`. All launcher icons, wallpapers and glass materials are original artwork drawn in Compose.

> **Accuracy note.** This gallery targets macOS 27 Golden Gate (released 14 September 2026), not macOS 26 Tahoe. Golden Gate is the release that tightened window corners, removed floating inset sidebars, restored colored sidebar icons, added the Liquid Glass opacity slider and introduced Siri AI with a unified “Search or Ask” Spotlight.

## How to read an entry

`Category` groups the shot. The **Recreate** line is the implementation intent used in this project — proportions, material behaviour and interaction — not a pixel-copy instruction.
